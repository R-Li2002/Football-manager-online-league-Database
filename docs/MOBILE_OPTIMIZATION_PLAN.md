# HEIGO 移动端重置计划

更新时间：2026-07-02

## 目标

移动端重置不是把桌面版简单压缩，而是为手机端建立一套独立但一致的使用体验。整体继续保持主站现有的轻量圆角、透明质感、仿苹果风格，同时优先保证核心数据可读、可点、可操作。

核心目标：

- 手机竖屏无明显横向溢出。
- 队名、教练名、球员名等关键文字尽量完整展示。
- 表格类页面在手机端提供卡片化或分段切换方案。
- 弹窗、高级筛选、阵容预览等复杂交互适配小屏。
- 管理员、工作账号、教练账号的操作入口在移动端仍然清晰。
- 图片保存、拖拽、比分编辑等重点功能在手机端可用。

## 阶段 0：基线审计

目标：确认真实移动端问题，避免盲改。

### 2026-07-02 基线审计记录

审计方式：

- 使用 Playwright 打开 `http://127.0.0.1:8080/`。
- 视口覆盖 `375 x 667`、`390 x 844`、`844 x 390`、`768 x 1024`。
- 页面覆盖首页、联赛概览、联赛名单、球员库、教练主页、积分榜、赛程、球员榜、伤停、冠军杯、联盟杯、无铭剑杯。
- 检查 body 级横向溢出、内部大宽度元素、过小点击目标、高级搜索弹窗尺寸和浏览器 console 错误。

主要结论：

- 手机竖屏 `375` 和 `390` 下，主页面没有出现 body 级横向滚动，说明外层容器基础约束有效。
- 主导航在手机竖屏下依赖横向滚动，后面的“教练主页”“球员库”等 tab 位于首屏右侧，需要主动横滑才能看到。当前能用，但发现性不够强。
- 顶部操作按钮“加入Heigo”“导出 Excel”“切换夜间”高度约 `36px`，低于移动端建议的 `40px - 44px`。
- 首页“进入教练主页”、球员库“搜索”、教练页“教练登录/刷新”等按钮也存在 `36px - 38px` 高度偏小的问题。
- 数据统计二级 tab 中“赛程”“伤停”按钮宽度约 `38px`，虽然高度达到 `44px`，但横向触控面积偏小。
- 联赛概览表格在 375/390/768 宽度下仍是大宽表，内部宽度约 `1061px - 1285px`，需要横向滚动。
- 联赛名单表格在 375/390/768/844 横屏下仍是大宽表，内部宽度约 `1251px - 1310px`。桌面数据完整，但手机端默认阅读成本高。
- 赛程表在 375/390/768 下内部宽度约 `800px`，手机端仍依赖横向滚动，不适合比分编辑。
- 积分榜在本轮检查中没有 body 级横向溢出，当前比普通宽表更稳定，但仍需要进一步人工检查队名、教练名的完整展示。
- 无铭剑杯在 `844 x 390` 横屏下出现 body 级横向溢出，页面 scrollWidth 达到约 `1198px`。溢出来源包括 `cup-bracket-board`、`cup-bracket-shell`、`cup-hero` 以及外层 competition 容器。这是杯赛移动端专项中的高优先级问题。
- 高级搜索在 `390 x 844` 下打开后，`dbAdvancedSearchPanel` 约 `366 x 796px`，位置从 `top: 250px` 到 `bottom: 1046px`，超出视口底部。需要改为全屏 sheet 或内部固定滚动区域。
- 浏览器 console 中存在多条教练头像资源 404，路径集中在 `/static/uploads/coaches/*.webp`。这不是移动端布局问题，但会影响教练页头像展示和加载噪音，应在教练主页优化阶段顺手处理。

初步优先级：

1. 修复无铭剑杯横屏 body 级横向溢出。
2. 高级搜索移动端改为全屏 sheet 或可滚动 bottom sheet。
3. 将全站移动端按钮高度统一提升到 `40px - 44px`。
4. 数据统计二级 tab、级别 tab 提升触控面积并优化横滑提示。
5. 联赛名单移动端默认卡片视图，表格降为高级视图。
6. 赛程移动端卡片化，比分编辑和一键保存适配手机。
7. 联赛概览球队列表移动端默认卡片视图。
8. 继续人工复核积分榜队名、教练名和主/客/总数据在手机端的真实阅读效果。
9. 教练头像 404 做数据修复或前端 fallback。

审计尺寸：

- 375 x 667：小屏手机
- 390 x 844：主流 iPhone 尺寸
- 430 x 932：大屏手机
- 844 x 390：手机横屏
- 768 x 1024：平板竖屏

审计页面：

- 首页
- 联赛名单
- 球队列表
- 数据统计
- 积分榜
- 赛程
- 伤停
- 球员榜
- 球员库
- 高级搜索
- 教练主页
- 杯赛对阵图
- 阵容预览

检查项：

- 是否出现横向溢出。
- 文字是否被截断、重叠或遮挡。
- 按钮和筛选控件是否足够容易点击。
- 表格是否因列数过多导致信息不可读。
- 弹窗是否超出屏幕或不在可操作区域。
- 页面切换动画是否轻量顺滑。
- 图片、队徽、头像、奖杯是否在移动端显示自然。
- 登录后编辑入口是否清楚，权限是否不受影响。

交付结果：

- 移动端问题清单。
- 第一批全局移动端样式基线。
- 后续阶段的优先级排序。

## 阶段 1：全站移动端骨架重置

目标：先让所有页面在手机上站得住。

### 2026-07-02 执行记录

已完成：

- 追加移动端阶段 1 覆盖样式，限制 `html/body` 横向溢出。
- 手机端主容器边距调整为更紧凑的 `14px / 12px`。
- 手机端卡片、搜索区、表格容器、数据统计 shell 统一收敛到 `18px` 圆角。
- 全站主要移动端按钮、导航 tab、数据统计二级 tab、级别 tab 的最小触控高度提升到 `44px`。
- 主导航、数据统计二级 tab、级别 tab 统一为横向滚动、隐藏滚动条、保留 scroll snap。
- 高级搜索在手机端改为贴合视口的全屏 sheet，使用 `100dvh` 和安全区 padding。
- 高级搜索打开时禁用当前 tab/list-view 的 transform，避免 fixed 面板被页面切换动画祖先偏移。
- 高级搜索内部内容区可滚动，底部操作区保持可见。
- 手机横屏和低高度视口下，杯赛 bracket 强制单列收敛，避免撑爆 body。
- 修复无铭剑杯在 `844 x 390` 横屏下的 body 级横向溢出。

验证结果：

- 健康检查：`/health` 返回 `{"status":"ok","database":"ok"}`。
- 静态资源版本：`app.css?v=0.2.86`。
- 高级搜索 `390 x 844`：面板位置 `left: 0, top: 8, right: 390, bottom: 844`，不再超屏。
- 高级搜索 `390 x 844`：body 无横向溢出。
- 主导航和顶部按钮高度：`44px`。
- 无铭剑杯 `844 x 390`：body 无横向溢出，`scrollWidth` 为 `844`，bracket 宽度收敛到 `796px`。

工作内容：

- 一级导航在手机端改为横滑、折叠或底部导航形态，避免所有 tab 同时挤在一行。
- 页面左右边距统一到 12px - 14px。
- 卡片、面板、表格容器统一圆角和内边距。
- 所有可点击控件移动端最小高度控制在 40px - 44px。
- 普通弹窗移动端改为 bottom sheet。
- 高级搜索、阵容预览、荣誉编辑等复杂弹窗改为全屏 sheet。
- 页面切换使用轻量 `opacity + translateY` 动画，并遵守 `prefers-reduced-motion`。

验收标准：

- 核心页面无明显横向溢出。
- 导航在手机端可完整访问。
- 弹窗不超屏，底部操作不被手势条遮挡。

## 阶段 2：首页与搜索体系优化

目标：让手机用户最快完成查球员、查球队、进统计。

### 2026-07-02 执行记录

已完成：

- 首页数据徽章移动端重排为三列：联赛球队、联赛球员、球员库球员；模式状态独占一行。
- 首页移动端首屏压缩：搜索区、说明文字、公告、入口卡片间距和字号整体收敛。
- 首页四个主入口移动端固定为 `2 x 2` 卡片布局。
- 首页搜索从单纯球员库搜索扩展为轻量统一搜索：
  - 球队：按队名、主教练、级别匹配。
  - 联赛球员：按姓名、UID、球队、位置、国籍匹配。
  - 教练：按昵称、球队、级别、称号匹配。
  - 球员库：继续使用后端球员库搜索接口。
- 首页搜索结果按“球队 / 联赛球员 / 教练 / 球员库”分组展示。
- 教练搜索结果点击后跳转到对应教练主页。
- 球员库结果保留“查看全部”入口，仍可进入球员库完整结果页。
- 高级搜索入口继续从首页搜索框带入关键词，并使用阶段 1 的移动端全屏 sheet。

验证结果：

- 健康检查：`/health` 返回 `{"status":"ok","database":"ok"}`。
- 静态资源版本：`app.css?v=0.2.88`，`app.home.js?v=0.2.88`。
- `390 x 844`：首页无 body 横向溢出。
- `390 x 844`：三个数据徽章为三列，模式状态独占一行。
- `390 x 844`：四个首页入口为 `2 x 2` 布局。
- `390 x 844`：搜索 `Chelsea` 可显示球队、联赛球员、教练分组。
- `390 x 844`：搜索 `messi` 可显示球员库分组和“查看全部”入口。
- `390 x 844`：从首页打开高级搜索不超屏。
- `375 x 667`：首页搜索结果无 body 横向溢出；点击教练结果后进入教练主页。

工作内容：

- 联赛球队数、联赛球员数、球员库球员数改为紧凑数据徽章。
- 四个主入口移动端改为 2 x 2 卡片。
- 公告改为轻量横幅。
- 搜索结果按球队、联赛球员、球员库球员、教练分组。
- 高级搜索移动端改为全屏筛选页，底部固定“应用筛选 / 清空筛选”。

验收标准：

- 首页首屏不被说明文字撑得过长。
- 搜索和高级搜索入口清晰。
- 高级搜索在 390px 宽度下不偏移、不超屏。
